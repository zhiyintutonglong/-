字体说明
========

zh.ttf 是游戏在 Android 上显示中文所必需的。

【重要 · 版权提示】
当前这份 zh.ttf 是从你本机 C:\Windows\Fonts\simhei.ttf 复制的「黑体」，
版权归 Microsoft 所有，随 Windows 授权。
- 自己装机、自己玩、不对外分发：通常没问题
- 若要发布到应用商店 / 公开分发：请务必换成开源字体

【推荐替换成开源字体】（下载后直接改名为 zh.ttf 覆盖即可）
- 思源黑体 / Noto Sans SC  (SIL Open Font License, 可商用)
  https://github.com/notofonts/noto-cjk  文件: NotoSansSC-Regular.ttf
- 文泉驿微米黑             (GPL+FE, 可商用)
  http://wenq.org/wqy2/

【不放字体会怎样】
Android 系统里没有微软雅黑/黑体，游戏里的中文会变成方块或空白。
所以打包前请确保本目录下有 zh.ttf。
